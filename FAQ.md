# Frequently Asked Questions

## What is Muse?

Muse is Meta's personal AI agent. A normal chatbot gives you text and stops
there. An agent can also do things for you: browse the web and read pages,
work with email and calendar if you connect them, build documents and files,
and run scheduled checks in the background.

## Do I have to use an invite code to use Muse?

No. You can use Muse without any code. A code only affects the starting
usage credit, not what the agent can do. See the "Invite, with full
disclosure" section at the end of `README.md` for the terms.

## What is the 48-hour rule?

A new user can redeem an invite code only within 48 hours of joining. After
that window, the redemption option disappears, and joining earlier does not
help. If you joined a week ago, the window has already passed.

## How many times can a code be used?

Two limits apply. First, each account can redeem only once. Second, the
person sharing the code earns the bonus for up to 20 friends, and each code
stops working after roughly 20–30 redemptions in total. If a code will not
go through, it is most likely full.

## Are the bonus tokens money?

No. They are usage credit for Muse. They cannot be withdrawn, transferred,
or valued like cash. They only give you more usage to start with.

## Is Muse available everywhere?

No. Muse is currently open mainly to users in the US and Canada. An invite
code does not bypass regional availability or any waitlist.

## Is it safe to let an agent touch my email or calendar?

Only with a standing rule: ask before sending, spending, deleting, or
changing anything outside the chat. Connect one thing at a time, start with
small and reversible tasks, and check numbers, dates, and names before you
use any result. Do not hand an agent an irreversible action and walk away.

## What if the agent makes a mistake?

It will, eventually. That is why this workflow keeps a human check on the
important parts. When a first draft needs a correction, fix the prompt, not
just the answer — add the exact check the prompt was missing, for example
"quote the date from the source, do not rephrase it."

## Where do I start?

Start with the morning inbox prompt in `prompts.md` and the morning section
of `daily-workflow.md`. Run those for a week before adding research,
documents, or watchdogs.
