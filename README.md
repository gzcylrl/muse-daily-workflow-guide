# A Small Daily Workflow for Working with an AI Agent

This repo is a practical workflow, not a review and not a sales page. It describes
how I use Muse, Meta's personal AI agent, for ordinary work: inbox triage,
research, turning messy notes into documents, and keeping an eye on a few things
on a schedule.

If you are looking for a tool that works with no checking at all, this workflow
is not for you. The whole point here is to keep a human in charge of the
important parts.

## Who this workflow is for

- You have a lot of small, boring tasks and limited patience for new tools.
- You are willing to check numbers, dates, and names before you use a result.
- You want the agent to do the first draft, not to make the final decision.

## Set it up in 15 minutes

1. Join Muse and connect only one thing first. For most people, that is email,
   or nothing at all. You do not need to connect everything on day one.
2. Set one rule and keep it: ask me before you send, spend, delete, or change
   anything outside this chat. This rule is why I trust the agent with real work.
3. Give it one small, boring task first: inbox triage, a trip plan, or a messy
   spreadsheet. Do not start with money, messages to other people, or anything
   hard to undo.
4. Check the result before you use it. Especially numbers, dates, and names.
   The agent is fast, and fast is exactly when a small error slips through.

## The morning routine

1. Ask for the inbox summary: security alerts, bills, support replies, and
   things that expire. Skip the marketing pile.
2. On a quiet day, a good answer is silence. A daily "all is normal" is exactly
   how you learn to ignore a tool, so I do not ask for one.
3. Pick the one task that actually needs doing today and hand it over first.
   The rest can wait.

See [daily-workflow.md](daily-workflow.md) for the full checklist.

## The afternoon routine

1. Research: compare two options, check a price, or read a long document and
   return only the part that matters, with sources I can open.
2. When the agent cannot verify something, I want it to say so. I trust that
   sentence more than a confident paragraph with no source.
3. Documents: messy notes in, a clean summary, plan, or comparison table out.
   I still edit before I send anything. I no longer start from a blank page.

## Watchdogs, not reports

I ask the agent to watch a few things on a schedule and to tap me only when
something changes. Examples:

- A price, a deadline, or a reply I am waiting for.
- A page that updates rarely but matters when it does.
- A recurring check that I would otherwise forget.

If nothing changed, I do not need a message about it.

## What I do not hand it

- Sending messages or money on my behalf without my explicit approval.
- Deleting files, accounts, or records.
- Anything where a mistake would be hard to undo, unless I have checked the
  exact action first.
- Decisions that need my judgment, not just information. The agent can gather
  the facts; I make the call.

## The honest limits

- Muse is currently open to users in the US and Canada. Joining does not
  bypass regional availability or any waitlist.
- Bonus tokens are usage credit for Muse. They are not money, and they cannot
  be withdrawn.
- No agent, this one included, should be left alone with irreversible actions.
  If a tool promises that, do not use it for real work.
- The agent remembers context across conversations, which saves re-explaining
  things every morning, but it does not replace checking the important parts.
