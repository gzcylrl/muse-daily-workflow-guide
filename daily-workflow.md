# Daily Workflow Checklist

Run this once a day. It is designed to take a few minutes, not an hour.
Skip any step that does not apply that day.

## Morning

- [ ] Ask for the inbox summary: security alerts, bills, support replies,
      and things that expire soon. Skip marketing mail.
- [ ] If the summary is empty, move on. Silence on a quiet day is a good
      result, not a failure.
- [ ] Pick the one task that actually needs doing today and hand it over
      first. The rest can wait.
- [ ] Check any watchdog alert from overnight before you start new work.

## Afternoon

- [ ] Research: one comparison, one price check, or one long document read
      — with sources for every key fact.
- [ ] Documents: turn one messy set of notes into a clean summary, plan,
      or comparison table. Edit before you send anything.
- [ ] Check numbers, dates, and names in any result before you use it.
      This is the one check you never skip.

## Evening

- [ ] Confirm nothing was sent, spent, deleted, or changed without your
      approval today. If something was, note it and tighten the rule.
- [ ] Write down one task that saved real time and one task where the
      first draft needed a correction.
- [ ] Leave tomorrow's first task written down, so the morning starts with
      one clear job instead of a blank page.

## Weekly (once, not daily)

- [ ] Run the weekly review prompt in `prompts.md`.
- [ ] Drop one task that keeps needing corrections, or rewrite its prompt
      with the exact check it keeps missing.
- [ ] Check whether any watchdog is still useful. Remove watchdogs that
      only produce noise.
- [ ] Re-read your standing rule: ask before sending, spending, deleting,
      or changing anything outside the chat. If you relaxed it during the
      week, put it back.

## Rules that keep this safe

1. The agent drafts. You decide. Especially for messages and money.
2. One new connection at a time. Do not connect everything on day one.
3. Sources for facts, silence for quiet days, and a check before use.
   Those three habits are the whole workflow.
